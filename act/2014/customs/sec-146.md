# 146. Unique user identifier
(1) The Comptroller must allocate to a registered user a unique user identifier in a form or of a nature determined by the Comptroller.
(2) The unique user identifier allocated under subsection (1) must be used by the registered user for the purpose of transmitting information to or receiving information from that Customs computerised entry processing system.
(3) The Comptroller may, by notice in writing, impose conditions on a particular registered user, or on registered users generally, on the use and security of unique user identifiers.
