# 8. Code of ethics
(1) The Institute must have a code of ethics that governs the professional conduct of its members.
(2)The code of ethics must be prescribed by the Council.
(3)The Council must, no later than 90 days after the day on which this Act comes into force, deliver a copy of the code to the Registrar for registration.
(4) The Council may amend or revoke the code.
(5) Revocation of the code shall become effective upon the date of registration of the replacement code delivered by the Council to the Registrar.
(6) The Council must, no later than 90 days after passing any amendment to the code or replacing the code, deliver to the Registrar for registration a copy of the amendment or the new code.
