# 8. Description of collateral
(1) A general or specific description of collateral in a security agreement or notice is sufficient if it:
(a) identifies collateral by item or kind in a manner that enables the collateral to be identified; or
(b) consists of a statement that a security interest is taken in all of the debtor's present and after-acquired property; or
(c) consists of a statement that a security interest is taken in all of the debtor's present and after-acquired property except for specified items or kinds of personal property.
(2) To be sufficient, a description of consumer goods must have a specific description.
